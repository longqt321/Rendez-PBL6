# Evaluation Rubric: Evidence-Based Decision-Making

| Dimension | Level 1: Novice / Fail | Level 2: Competent / Pass | Level 3: Exemplary / Proficient |
| :--- | :--- | :--- | :--- |
| **1. Reversibility Framing** | Treats all decisions identically, leading to either reckless irreversible changes or paralysis on minor items. | Identifies whether the decision is high-impact (One-Way) or low-impact (Two-Way). | Explicitly classifies reversibility, calculates blast radius, and defines an atomic escape hatch/rollback plan. |
| **2. Multi-Criteria Rigor** | Compares only 1 dimension (e.g., pure raw speed) while ignoring maintenance and operational failure modes. | Uses a structured table comparing at least 2 options across multiple criteria. | Normalized weighted matrix with operational complexity, cost, maintainability, and empirical benchmarks. |
| **3. Evidence Substantiation** | Assigns scores based on personal gut feeling or framework popularity. | Cites concrete documentation or simple local prototypes for key scores. | Backs scores with reproducible spike measurements, profiling traces, or historical system invariants. |
| **4. ADR Completeness** | Announces a decision in chat without recording the forces, trade-offs, or accepted technical debt. | Writes an ADR document recording the choice and positive reasons. | Formal ADR capturing context, forces, choice, explicit negative consequences, and verification triggers. |
