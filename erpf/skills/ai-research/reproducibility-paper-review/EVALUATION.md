# Evaluation Rubric: Reproducibility Assessment and Scientific Paper Review

| Dimension | Level 1: Novice / Fail | Level 2: Competent / Pass | Level 3: Exemplary / Proficient |
| :--- | :--- | :--- | :--- |
| **1. Reproducibility & Artifact Audit** | Ignores code repository; checks only PDF formatting without testing script validity. | Checks that a GitHub repository link exists and dependencies are listed. | Audits code for data leakage, validates random seeds, checks NeurIPS checklist, and runs sandbox reproduction. |
| **2. Claims-to-Evidence Alignment** | Overlooks sweeping hype language ("revolutionary", "optimal"); accepts claims at face value. | Flags obvious overclaiming statements in Abstract. | Constructs a formal 1:1 Claims-to-Evidence matrix; requires calibrated academic hedging for every major thesis. |
| **3. 4-Axis Review Structure** | Writes vague 3-sentence reviews ("looks good", "reject because bad"); mixes opinions with facts. | Evaluates Soundness, Novelty, and Empirical Rigor in separate paragraphs. | Rigorous 4-axis evaluation, clearly separates Fatal Flaws from minor concerns, and provides constructive questions. |
| **4. Professional Rebuttal Tone & Evidence** | Adopts defensive, emotional tone; argues with reviewers without providing new data. | Responds politely to reviewer concerns with textual clarifications. | Evidence-driven rebuttal: structured point-by-point format, cites specific code diffs, seeds, and supplementary tables. |
