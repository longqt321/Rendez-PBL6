# Product Vision

Rendez is a visual-first place discovery platform. Users discover places through real photos and community data, not ads.

## Principles
- Visual Truth: photos reflect real places.
- No AI in current scope.
- Deterministic algorithms only.

## Scope
Place types: dining, cafes/beverages, entertainment, sightseeing/tourism, public spaces, shopping, activities/experiences, and other discoverable places.

## Geographic
Architecture supports expansion beyond any single city; test data may start in one city.

## Place kinds
Business, public space, other. Do not assume all places are businesses.
