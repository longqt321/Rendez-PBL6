# Product Requirements

## Core features
- Visual feed discovery (REQ-01)
- Search and filters (REQ-02)
- Map exploration (REQ-03)
- Place detail with photos (REQ-04)
- Save places (REQ-05)
- Contribute photos (REQ-06)
- Interactions: likes/comments (REQ-07)
- Share (REQ-08)

## Non-functional
- Accessibility, responsive, performance, data integrity.

## Out of scope
- AI/ML, booking/reservations, ratings/reviews detailed, AI search.

## MVP boundary
Visual discovery + map + save + contribute + interactions.
